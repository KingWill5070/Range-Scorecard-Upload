# Range Scorecard Upload System — V1

A full-stack role-based military range scorecard management system built with FastAPI and vanilla HTML/JS. Includes Soldier → NCO → Officer → Admin workflows, file uploads, readiness tracking, and a complete chain-of-command dashboard system.

---

## 🚀 Features

### Soldier
- Upload range scorecards
- View uploaded files
- Score-based legacy term calculation

### NCO
- Assign soldiers
- Review uploads
- Approve / reject
- Readiness tracking with color-coded bar

### Officer
- Assign NCOs
- View platoon hierarchy
- Review soldier uploads
- Approve / reject
- Readiness summary + color-coded readiness bar

### Admin
- Create users
- Delete users
- Update roles
- View system metrics
- Full hierarchy visualization

---

## 🛠 Tech Stack
- FastAPI
- SQLAlchemy
- SQLite
- Vanilla HTML/CSS/JS
- Static file serving
- Role-based access control
